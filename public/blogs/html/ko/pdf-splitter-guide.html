PDF를 품질 손실 없이 분할하는 방법

THRJ의 PDF Splitter 사용에 대한 간단한 가이드입니다. 원본 품질을 유지하면서 페이지를 빠르게 분할할 수 있습니다 — PDF Splitter 열기 또는 /pdf-splitter 사용.


개요

PDF Splitter를 사용하면 PDF에서 페이지 또는 범위를 추출하여 원본 이미지를 재인코딩하거나 축소하지 않고 별도의 문서로 저장할 수 있습니다. 공유, 아카이빙 또는 특정 페이지 추출에 유용합니다.


빠른 단계

  1. https://thrjtech.com/pdf-splitter 또는 /pdf-splitter를 방문합니다.
  2. PDF를 업로더에 드래그 앤 드롭하거나 클릭하여 파일을 선택합니다.
  3. 추출할 페이지를 선택합니다 (단일 페이지, 3-5와 같은 범위, 또는 미리보기로 선택).
  4. 분할을 클릭하고 처리를 기다립니다.
  5. 준비가 되면 추출된 PDF를 다운로드합니다.

스크린샷과 함께 단계별 안내

1. PDF 업로드

PDF를 드롭하거나 파일 선택기를 사용합니다. 업로더는 파일 이름과 크기를 표시하고, 가능할 경우 페이지 미리보기를 제공합니다.

2. 페이지 또는 범위 선택

추출할 페이지 또는 범위를 선택합니다. 단일 페이지 또는 연속된 범위를 선택할 수 있으며, 도구는 원본 해상도와 형식을 유지합니다.

3. 분할 및 다운로드

분할을 클릭합니다. 진행 표시기가 처리 상태를 보여줍니다. 완료되면 각 추출된 PDF에 대한 다운로드 링크 또는 배치 결과에 대한 ZIP 파일이 나타납니다.


모범 사례

  • 추가 페이지를 추출하지 않도록 분할 전에 페이지를 미리 봅니다.
  • 큰 PDF의 경우, 처리를 빠르게 유지하기 위해 배치로 추출합니다.
  • 다운로드된 파일은 원본 이미지 품질과 레이아웃을 유지합니다.
  • 나중에 다른 분할이 필요할 경우를 대비해 원본 사본을 보관합니다.

개인정보 보호 및 보관

업로드된 파일은 다운로드가 가능하도록 필요한 시간 동안만 보관되며, 짧은 보관 기간 후 삭제됩니다. 최대한의 개인정보 보호를 위해, 처리 속도를 높이기 위해 작은 파일을 사용하세요.


지원되는 입력

PDF 파일 (.pdf). 다중 페이지 PDF도 완전히 지원됩니다 — 추출된 페이지는 별도의 PDF 파일로 반환됩니다.


FAQ

분할하면 이미지 품질이 변경되나요? 아니요 — 분할은 이미지를 재인코딩하지 않고 페이지를 추출하므로 품질이 유지됩니다.

여러 비연속 페이지를 추출할 수 있나요? 예 — 원하는 페이지 조합을 선택하면 도구가 선택에 따라 별도의 파일 또는 결합된 출력물을 생성합니다.
